# PhpStorm MCP v1.3.0

This release improves the public README and install guidance for users who want the latest packaged skill without reading maintainer workflow documentation.

## Highlights

- Add a README quick install section with a direct link to the latest GitHub release.
- Explain which release ZIP to choose for standalone, Codex plugin, and Claude plugin installation.
- Document the common standalone target path: `.agents/skills/phpstorm-mcp/SKILL.md`.
- Add after-install guidance and an example request for invoking the skill in a PhpStorm MCP project.
- Align the package release script with the repository's Node global inspection directive pattern.

## Package Boundary

Release packages include only runtime skill files and plugin manifests. They exclude raw intake, local feedback notes, private research, repository docs, workflows, and temporary build output.

## Validation

Run before publishing:

```bash
npm run validate
npm run package -- v1.3.0
```
