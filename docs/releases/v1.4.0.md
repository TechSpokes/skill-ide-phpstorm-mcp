# PhpStorm MCP v1.4.0

This release adds JetBrains HTTP Client request-file guidance to the runtime skill and prepares the package metadata for the next minor release.

## Highlights

- Add a focused runtime reference for JetBrains HTTP Client `.http` and `.rest` request files.
- Route agents through PhpStorm MCP request run-point discovery and saved HTTP Request configurations.
- Document environment confirmation, response captures, downloads, response handler tests, request history, and empty-output verification.
- Classify high-risk HTTP Client workflows, including remote, credentialed, mutating, upload, download, response-writing, TLS-verification-disabled, cookie, WebSocket, GraphQL mutation, and debug requests.
- Add a repeatable disposable HTTP Client capability sweep for maintainers.
- Bump package and plugin manifest versions to `1.4.0`.

## Package Boundary

Release packages include only runtime skill files and plugin manifests. They exclude raw intake, local feedback notes, private research, repository docs, workflows, disposable HTTP probes, and temporary build output.

## Validation

Run before publishing:

```bash
npm run validate
npm run package -- v1.4.0
```
