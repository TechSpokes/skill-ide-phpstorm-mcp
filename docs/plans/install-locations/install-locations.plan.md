# Install Locations Implementation Plan

> For agentic workers: REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` or `superpowers:executing-plans` to implement this plan task by task. Steps use checkbox syntax for tracking.

## Goal

Update installation documentation so users know the concrete standalone skill locations that modern agent hosts read, while preserving the existing release ZIP layout guidance.

## Architecture

This phase changes documentation only. It updates `docs/INSTALL.md` and optionally tightens related README wording without changing packaging, runtime skill behavior, or release workflow logic.

## Repository Context

This repository packages one runtime skill, `phpstorm-mcp`, for standalone skill installation and plugin installation. Preserve the difference between repository source files and installed release artifacts.

When local judgment is needed, choose the wording that makes installation concrete for users while avoiding unsupported host paths or claims that are not documented in this repository.

## Tech Stack

- Markdown documentation under `docs/`.
- Existing release asset names generated by `scripts/package-release.mjs`.
- Repository validation through `npm run validate`.

## Preconditions

- Read `AGENTS.md`, `.github/instructions/markdown.instructions.md`, `docs/ROADMAP.md`, and this plan before editing.
- Run `git status --short` and preserve unrelated user changes.
- Do not change `scripts/package-release.mjs` or release asset names in this phase.

## Current State

Before this phase was implemented, `docs/INSTALL.md` explained the standalone ZIP structure with only generic host-directory wording.

The document does not identify `.agents/skills/` as the cross-tool repository location.

The document does not list `.claude/skills/`, `~/.claude/skills/`, or `.github/skills/` as tool-specific locations.

## Target State

`docs/INSTALL.md` starts by explaining that release ZIP contents should be installed, not clone-time repository scaffolding.

The standalone section recommends `.agents/skills/` for repository-shared skills.

The standalone section lists `.claude/skills/`, `~/.claude/skills/`, and `.github/skills/` as supported tool-specific locations.

The ZIP layout examples remain specific to `phpstorm-mcp`.
